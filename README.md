# Pricing Cards

Responsive SaaS pricing card component built with HTML, CSS and JavaScript.

## Features
- Three plans: Starter, Pro and Business
- Monthly / Yearly billing toggle that updates the prices
- CSS transitions and transform hover effects on the cards
- "Popular" and "Best Value" badge ribbons
- Responsive layout for mobile and desktop
